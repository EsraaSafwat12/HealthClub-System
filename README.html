USER ROLES
🔑

Admin

  • Dashboard with live stats & charts
  • Manage users (add, edit, lock/unlock)
  • Assign members to coaches
  • Create & track invoices
  • Generate PDF reports
  • Send notifications to members
  • Manage inventory & salaries
  • Coupons, freeze, family packages
  • Referrals, split payments, contracts
  • WhatsApp notifications
  • Body progress tracking
  • Revenue & attendance charts
🏋️

Coach

  • View assigned members
  • Create & manage schedules
  • Design workout plans
  • Track member attendance
  • Send messages to members
  • Generate coach PDF reports
  • Update personal info
🏃

Member

  • View subscription details
  • Access training schedule
  • View personalized workout plan
  • Check attendance history
  • View & track bills
  • Receive messages from coach/admin
  • Track body progress
  • Update personal info & PIN

HOW TO RUN
bash — HealthClub-System
# 1. Clone the repository
$git clone https://github.com/EsraaSafwat12/HealthClub-System.git
# 2. Install the core library first
$cd healthclubsystem && mvn install
# 3. Run the GUI application
$cd ../HealthClubGUI && mvn javafx:run
